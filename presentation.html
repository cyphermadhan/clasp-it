The problem

Describing UI bugs to Claude is painful.

01

You spot a broken element. You screenshot it, crop it, describe it — context lost in translation.

02

Copy-pasting HTML snippets into Claude misses the CSS, the computed styles, the network calls that matter.

03

Switching windows to get console errors means you lose your mental context and Claude loses the picture.

04

React component state is invisible in the DOM — you can't paste what you can't see.

What is
Clasp-it?

A Chrome extension that acts as a bridge between your browser and Claude Code. Click any element — and its entire context is waiting for Claude via MCP.

🖱️

Click to capture

Activate the picker with one click. Hover to highlight any element. Click to capture everything about it — instantly.

🔌

MCP-native delivery

Captured context appears as a pick in Claude Code via the Model Context Protocol. No copy-paste, no file drag, no switching apps.

🧠

Rich context, not just HTML

Goes beyond the DOM — computed styles, console logs, network requests, screenshots, and React component props included.

💬

Prompt-first workflow

Each pick comes with your prompt so Claude knows exactly what you want. Add attachments for richer visual context.

How it works

Three steps, zero friction.

1
🎯

Pick an Element

Click the extension icon to activate the picker. Hover over any element — the overlay highlights it. Click to capture.

→
2
✏️

A floating dialog appears beside the element. Type your prompt — "fix this layout" or "why is this failing?" Attach screenshots optionally.

→
3
⚡

The pick is available via MCP. Claude reads the full element context — no manual copy-pasting required.

→
4

When Claude marks the pick as completed, attachments are auto-deleted from cloud storage. Clean by default.

# Install once — picks arrive automatically
claude mcp add --scope user --transport http clasp-it https://claspit.dev/mcp \
  --header "Authorization: Bearer YOUR_KEY"

Security model

Built secure from the start.

🔑

API Key auth, no passwords

Signup uses magic links. Your API key (prefixed cit_) is generated server-side. No passwords stored ever.

🏗️

Extension → Server → R2

Attachments never go directly to cloud storage. All uploads route through the server, enforcing auth and quota checks at every step.

⏱️

1-hour signed URLs

Attachment links served to Claude expire in one hour. Even if a URL leaks, it becomes useless quickly.

🧹

Auto-delete by default

Attachments are removed when Claude marks a pick completed. A 28-day sweeper catches anything Claude never cleaned up.

🛡️

Server-side gating

Pro features are enforced server-side via gatePayload(). Client-side feature flags are UX only — not a trust boundary.

🔒

No secrets in logs

Raw API keys, magic link URLs, and webhook secrets are redacted from server logs. Sensitive data never leaks into observability pipelines.

✦

Context captured by the extension stays on your machine and your server. We never read your picks. Data is yours — we're the transport layer.
